# JS Cloud Kitchen — Premium Website

Files:
- index.html
- styles.css
- script.js
- assets/

## Before publishing
1. Open `script.js`.
2. Set `CONFIG.whatsappNumber` to the business WhatsApp number, digits only with country code.
   Example: `919876543210`
3. Set `CONFIG.phoneNumber`.
4. Update working hours, address and Google Maps link in `index.html`.
5. Replace the generic card labels/descriptions with the exact menu names and prices from the original menu once the source image is available in higher resolution.

The supplied low-resolution menu image is included as `assets/menu-reference.jpg` and its food photos are used as visual assets. No uncertain phone number, address, rating, award, or business claim has been invented.
